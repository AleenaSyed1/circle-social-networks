# Circle Social Network Platform

A real-time social networking platform developed as part of my **Web Development Internship at Arch Technologies — October 2026**.

## About the Project

Circle is a web-based social networking platform that allows users to create profiles, share posts, interact with other users, and receive notifications. The project demonstrates the use of frontend and backend technologies to build an interactive social networking application.

## Features

- User registration and login
- User profile management
- Create and share posts
- Like and comment on posts
- Send and manage friend requests
- Real-time updates
- Notifications
- Privacy settings
- Photo sharing

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- JSON for data storage

## How to Run

### Prerequisites
- Node.js installed on your computer
- A modern web browser

### Instructions

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Install the dependencies listed in `package.json`, if available.
4. Start the server using:

   ```bash
   node server.js
   ```

5. Open the following address in your browser:

   `http://localhost:3000`

**Note:** Follow the project's actual configuration if the startup command or port differs.
